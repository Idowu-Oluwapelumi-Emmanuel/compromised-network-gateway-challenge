# 🔐 Compromised Network Gateway Challenge

## 📌 Project Overview
This project simulates a real-world cyberattack and incident response investigation. I built a secure corporate network, simulated a brute-force SSH attack, installed a persistent backdoor, and investigated the incident using DFIR techniques.

## 🧩 Project Phases

### Phase 1: Network Design
- Designed a secure network using VLANs, ACLs, and Router-on-a-Stick
- Built with Cisco Packet Tracer (1 Router, 2 Switches, 4 VLANs, 8 PCs)

### Phase 2: Attack Simulation
- Simulated a brute-force SSH attack (54 failed attempts, 1 successful login)
- Installed a persistent backdoor with systemd persistence

### Phase 3: Digital Forensics & Incident Response
- Captured ICMP beacon traffic using Wireshark
- Identified malicious process (PID 19948)
- Traced persistence mechanism and analyzed logs

### Phase 4: Incident Reporting
- Wrote a professional MITRE-aligned Incident Report
